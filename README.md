- 用户自有账号升级所需资料由客服逐单确认，不索要 Google 密码、两步验证码或恢复码。
- Google AI Pro 一年成品账号是 Gemini 专属的独立交付路径，不适用于 ChatGPT、Grok 或 Claude。
- 不提供 API 额度、接码或批量注册。
- ChongGrok 与 Google 不存在隶属、授权或官方合作关系。

套餐、价格、库存、权益、额度和地区可用性以 Google 与 ChongGrok 实时页面为准。
